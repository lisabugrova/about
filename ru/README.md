## Профессиональные компетенции

- **Функциональное тестирование:** анализ требований, пользовательские сценарии, позитивные и негативные проверки, проверка правил интерфейса и бизнес-логики.
- **Регрессионное тестирование:** анализ влияния изменений, выбор проверок на основе рисков, повторное тестирование затронутых функций.
- **Проверка готовности релиза:** оценка покрытия, выявление блокирующих проблем и непроверенных областей, описание остаточных рисков.
- **Тестовая документация:** тест-кейсы, чек-листы, воспроизводимые баг-репорты, краткие отчёты о статусе тестирования.
- **Передача знаний:** поддержка повторно используемых тестовых материалов и подготовка коллеги к самостоятельной работе.

## Подход к тестированию

**Требования → Риски → Тест-дизайн → Выполнение тестов → Отчёты о дефектах → Оценка готовности релиза**

Методы выбираю в зависимости от особенностей функциональности: **разбиение на классы эквивалентности и анализ граничных значений** — для входных данных и ограничений; **таблицы решений** — для бизнес-правил; **тестирование переходов состояний** — для пользовательских процессов; **риск-ориентированный отбор** — для регресса.
