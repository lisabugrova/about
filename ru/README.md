## Audiodoc Studio

Audiodoc Studio расшифровывает аудио и видео и позволяет редактировать текст, сверяясь с записью. Представленные здесь примеры работ посвящены загрузке файлов и балансу времени обработки.

Несколько деталей из тест-дизайна:

- При проверке ограничения в десять файлов нужно дать аккаунту достаточно времени на обработку. Иначе ошибка баланса может скрыть проблему с ограничением очереди.
- Размер файла стоит проверять точно на границе, а не просто выбирать «большой файл».
- При нулевом балансе файл можно выбрать, но обычный запуск обработки должен оставаться недоступным.
