# Audiodoc Studio — регрессионные проверки и итоговая отчётность

**Область:** загрузка файлов, баланс времени обработки, результаты транскрибации  
**Основание для регресса:** изменения правил проверки баланса, очереди выбранных файлов либо загрузки и обработки  
**Подход:** анализ влияния изменений и риск-ориентированный выбор проверок.

## Анализ влияния изменений

| Затронутая область | Возможный регрессионный риск | Тестовое покрытие |
| --- | --- | --- |
| Проверка доступного времени | Пользователь начинает обработку без необходимого баланса либо допустимая загрузка блокируется | TC-BAL-001, TC-BAL-002, TC-BAL-003 |
| Очередь выбранных файлов | Некорректное состояние или устаревший результат валидации после выбора/удаления | TC-UPL-001, TC-UPL-006 |
| Способы выбора файлов | Обход валидации при drag-and-drop | TC-UPL-002, вариант TC-BAL-001 |
| Ограничения загрузки | Принимаются более 10 файлов либо файл свыше 1700 МБ | TC-UPL-003, TC-UPL-004, TC-UPL-005 |
| Загрузка и обработка | Процесс зависает, предупреждение не показывается или результат недоступен | TC-BAL-002 |
| Изменение баланса | Состояние выбранного файла не пересчитывается после пополнения | TC-BAL-004 |

## Приоритизированный набор регрессионных проверок

| Приоритет | Сценарий | Причина включения |
| --- | --- | --- |
| P0 | Баланс 0 с, видео 10 с: сообщение об ошибке и отсутствие действия загрузки | Критичное бизнес-ограничение |
| P0 | Баланс 1 час, видео 26:16: загрузка и получение результата | Основной пользовательский сценарий |
| P0 | Скачивание результата и открытие его в редакторе | Доступность результата обработки |
| P1 | Баланс D−1 / D / D+1 относительно длительности | Риск ошибки на границе и при округлении |
| P1 | Одинаковые проверки допуска через диалог выбора и drag-and-drop | Риск разных правил для альтернативных способов ввода |
| P1 | Ограничения: 11 файлов и превышение 1700 МБ | Соблюдение заявленных лимитов |
| P1 | Повторная валидация выбранного файла после изменения баланса | Риск устаревшего состояния |
| P2 | Очистка очереди и повторный выбор | Сценарий восстановления/удобства |
| P2 | Проверка интерфейса в поддерживаемых браузерах и разрешениях | Совместимость |

## Критерии завершения проверок

- Все проверки приоритета P0 выполнены на кандидатной сборке.
- Блокирующие дефекты рассмотрены, известные проблемы зарегистрированы.
- Невыполненные и заблокированные проверки P1/P2 перечислены явно.
- Изменённые требования, непроверенные окружения и остаточные риски отражены в отчёте.
- Владелец решения о релизе получил данные, достаточные для принятия решения.
