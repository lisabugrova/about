# Audiodoc Studio: результаты проверок загрузки

Два сценария из исходного портфолио.

| Тест-кейс | Условия | Зафиксированное поведение | Результат и подтверждение |
| --- | --- | --- | --- |
| TC-BAL-001 | Доступно 0 с; видео длительностью 10 с | Файл выбран; Insufficient balance; нехватка 10 секунд; обычное действие Start upload отсутствует | В исходном отчёте — «пройден»; описано наблюдение за интерфейсом |
| TC-BAL-002 | Доступно 3600 с; видео длительностью 26:16 | Готовность и действие Start upload; сообщается об обработке, предупреждении при уходе со страницы, скачивании и доступе к редактору | В исходном отчёте — «пройден»; готовность описана по скриншоту, завершение — со слов тестировщика |

Первый сценарий проверяет ожидаемое ограничение. Сообщение о недостаточном балансе — правильный результат.

## Подтверждающие материалы

Браузер, ОС, сборка и дата выполнения не записаны. Идентификаторы аккаунта и набора данных скрыты. Скриншоты описаны, но не приложены.

Поэтому результаты подтверждены в разной степени: поведение интерфейса описано для обоих сценариев; полный результат обработки в TC-BAL-002 известен со слов тестировщика.

## Следующие проверки

В исходном отчёте оставались невыполненными:

- 10-секундное видео при балансе 9/10/11 секунд.
- Проверка нулевого баланса при перетаскивании файла.
- Суммарная длительность файлов и округление.

Для новых прогонов нужно отдельно указать сборку, среду, дату и подтверждающие материалы.
