# Audiodoc Studio — запись о выполненных проверках загрузки

**Тип материала:** запись о прошлых проверках, сохранённая из существующего портфолио.  
**Область:** два сценария проверки баланса и загрузки. Расширенные справочные сценарии в других документах не являются результатами выполнения тестов.

## Результаты и подтверждающие материалы

| Тест-кейс | Условия | Зафиксированное фактическое поведение | Зафиксированный результат и его основание |
| --- | --- | --- | --- |
| TC-BAL-001 | Доступное время — 0 с; поддерживаемое видео длительностью 10 с | Файл выбран; отображается Insufficient balance; сообщение указывает на нехватку 10 секунд; обычное действие Start upload отсутствует | Зафиксирован статус «пройден» — описано наблюдение за интерфейсом |
| TC-BAL-002 | Доступное время — 3600 с; поддерживаемое видео длительностью 26:16 | Состояние готовности и действие Start upload; сообщается об успешной обработке, предупреждении при уходе со страницы, скачивании результата и доступе к редактору | Зафиксирован статус «пройден» — готовность описана по скриншоту; завершение обработки подтверждено словами тестировщика |

В TC-BAL-001 сообщение валидации — ожидаемое поведение по бизнес-правилу, а не дефект продукта. В TC-BAL-002 промежуточное состояние готовности и полный результат обработки подтверждаются разными источниками.

## Исходные сведения о выполнении

| Поле | Имеющиеся сведения |
| --- | --- |
| Приложение | Audiodoc Studio |
| Медиафайлы | Поддерживаемые видео длительностью 10 секунд и 26:16 |
| Браузер / ОС | В предоставленных материалах не указаны |
| Сборка / релиз | В предоставленных материалах не указаны |
| Дата выполнения | В предоставленных материалах не указана |
| Идентификаторы аккаунта и набора данных | Скрыты в исходном отчёте |
| Скриншоты | Описаны в исходном отчёте; вложения отсутствуют |

Сведения о сборке и среде, вложения и новые успешные результаты не восстанавливались по исходному коду.

## Последующие проверки

В исходном отчёте следующими проверками были обозначены условия запуска при балансе 9/10/11 секунд, drag-and-drop при нулевом балансе, суммарная длительность файлов и округление. В этом документе они по-прежнему **не зафиксированы как выполненные**.

При новом прогоне укажите сборку, среду, дату, идентификатор тестового набора, фактические наблюдения и свидетельства без конфиденциальных данных. Разделяйте прежний и новый результаты; не приписывайте этой записи новую сборку задним числом.
