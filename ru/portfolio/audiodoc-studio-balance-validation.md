# Audiodoc Studio — тест-дизайн проверки баланса и обработки видео

**Функциональность:** баланс времени обработки → выбор файла → загрузка → результат  
**Вид тестирования:** функциональное; позитивные и негативные проверки  
**Техники:** разбиение на классы эквивалентности (EP), таблицы решений, анализ граничных значений (BVA), тестирование переходов состояний  
**Цель:** проверить достаточность баланса относительно длительности видео и основной успешный сценарий обработки.

## Основание для тестирования

| ID | Бизнес-правило / ожидаемое поведение |
| --- | --- |
| BAL-01 | Файл можно выбрать даже при недостаточном балансе **Available time**. |
| BAL-02 | При недостатке времени файл получает состояние **Insufficient balance**; интерфейс показывает недостающее время, начать загрузку нельзя. |
| BAL-03 | При достаточном времени файл получает состояние **Ready to upload!**, доступна кнопка **Start upload!**. |
| BAL-04 | После нажатия **Start upload!** во время загрузки/обработки показывается предупреждение не покидать страницу. |
| BAL-05 | После успешной обработки результат можно скачать или открыть в редакторе. |

## Тестовые данные

| Набор | Доступное время | Длительность видео | Назначение |
| --- | --- | --- | --- |
| BAL-D01 | **0 секунд** | **10 секунд** | Недостаточный баланс |
| BAL-D02 | **1 час** (3600 с) | **26 мин 16 с** (1576 с) | Достаточный баланс; успешный сценарий |
| BAL-D03 | **9 секунд** | **10 секунд** | На 1 секунду меньше длительности видео |
| BAL-D04 | **10 секунд** | **10 секунд** | Баланс равен длительности видео |
| BAL-D05 | **11 секунд** | **10 секунд** | На 1 секунду больше длительности видео |

**Тестовые файлы:** `sample_video_10s.mp4` — 10 с (BAL-D01, BAL-D03–05); `sample_video_26m16s.mp4` — 26 мин 16 с (BAL-D02).

| EP-BAL-03 | Баланс **10 секунд**, видео **10 секунд** | Проверка равенства баланса и длительности |

## Тест-кейсы

### TC-BAL-001 — Запрет загрузки при недостаточном балансе

**Предусловия и тестовые данные:** пользователь авторизован; **Available time = 0 seconds**; поддерживаемый файл **`sample_video_10s.mp4`**, длительность **00:00:10**; очередь выбранных файлов пуста.

1. Открыть **Your documents**.
2. Убедиться, что **Available time** показывает **0 seconds**.
3. Выбрать видео длительностью 10 секунд.
4. Проверить сообщение валидации и доступность загрузки.

**Ожидаемый результат:** файл отображается в списке со статусом **Insufficient balance**. Сообщение указывает, что необходимо ещё **10 секунд**. Кнопка **Start upload!** недоступна, обработка не начинается; пользователь понимает, что требуется дополнительное время.

### TC-BAL-002 — Обработка видео при достаточном балансе

**Предусловия и тестовые данные:** пользователь авторизован; **Available time = 1 hour (3600 с)**; поддерживаемый файл **`sample_video_26m16s.mp4`**, длительность **00:26:16 (1576 с)**; очередь выбранных файлов пуста.

1. Открыть **Your documents** и выбрать видео.
2. Проверить статус файла и доступные действия.
3. Нажать **Start upload!**.
4. Проверить процесс загрузки/обработки и предупреждение о запрете покидать страницу.
5. Дождаться завершения обработки.
6. Скачать результат и открыть его в редакторе.

**Ожидаемый результат:** показано **Ready to upload!**, доступна кнопка **Start upload!**; загрузка и обработка выполняются с предупреждением не покидать страницу; после завершения работают оба действия с результатом.

### TC-BAL-003 — Проверка границы достаточности баланса

**Предусловия и тестовые данные:** файл **`sample_video_10s.mp4`**, длительность **00:00:10**; три независимых состояния тестового аккаунта: баланс **9 с**, **10 с**, **11 с**. Перед каждой проверкой очищать очередь.

1. Установить баланс **9 секунд**, выбрать **`sample_video_10s.mp4`** длительностью **00:00:10**.
2. Зафиксировать статус **Insufficient balance** / **Ready to upload!**, недостающее время и доступность **Start upload!**.
3. Очистить очередь, установить баланс **10 секунд** и выбрать тот же файл; записать результат.
4. Повторить с балансом **11 секунд** и сравнить состояния загрузки для всех трёх значений.

**Ожидаемый результат (модель посекундного расчёта):** при **9 с** — **Insufficient balance**, нехватка **1 с**; при **10 с** и **11 с** — **Ready to upload!**, доступна кнопка **Start upload!**.

### TC-BAL-004 — Повторная проверка после пополнения баланса

**Предусловия и тестовые данные:** авторизованный тестовый аккаунт с балансом **0 секунд**; выбран **`sample_video_10s.mp4`** длительностью **00:00:10**, статус **Insufficient balance**; в тестовой среде доступно санкционированное изменение баланса с **0 секунд** до **1 часа**.

1. Убедиться, что запуск загрузки/обработки недоступен.
2. Найти элементы **Purchase time**.
3. В разрешённой тестовой среде увеличить баланс с **0 секунд** до **1 часа (3600 секунд)** без несанкционированной реальной оплаты.
4. Повторно проверить выбранный **10-секундный** файл без изменения данных.

**Ожидаемый результат:** при недостаточном балансе обработка недоступна; после поступления достаточного времени файл становится доступен к загрузке согласно согласованному правилу обновления состояния.

## Покрытие переходов состояний

| Исходное состояние | Событие / условие | Ожидаемое следующее состояние |
| --- | --- | --- |
| Файл не выбран | Выбрать допустимый файл при недостаточном балансе | **Insufficient balance** |
| Файл не выбран | Выбрать допустимый файл при достаточном балансе | **Ready to upload!** |
| Ready to upload | Нажать **Start upload!** | Загрузка / обработка |
| Загрузка / обработка | Успешное завершение | Обработано |
| Обработано | Нажать **Download** или **Open in editor** | Результат доступен |

**Дополнительно специфицировать:** потерю соединения, сбой обработки, повторную попытку, удаление файла из очереди, уход со страницы и изменение баланса после выбора.
