## Тест-кейсы: загрузка и баланс

**Задача:** проверить правила выбора файлов и допуска к обработке. Это тест-дизайн; таблица не содержит результатов выполнения.

**Общие условия:** пользователь авторизован, очередь пуста, MP4-файлы корректны. Для проверки количества — разные файлы по 10 секунд и баланс 3600 секунд. Для проверки размера баланса должно хватать на каждый файл; длительность не фиксируется.

### Выбранные тест-кейсы

| Проверка | Данные и действие | Ожидаемый результат |
| --- | --- | --- |
| TC-UPL-003 · На границе и ниже лимита | Выбрать 9 файлов, очистить очередь и выбрать 10. | В первой попытке принято 9 файлов, во второй — 10. |
| TC-UPL-004 · Превышение лимита | Выбрать 11 файлов. | Принято не больше 10 файлов; показано сообщение об ограничении. |
| TC-UPL-005 · Граница размера | Подтвердить лимит **L** в байтах. Поочерёдно выбрать корректные файлы **L−1**, **L**, **L+1** байт, каждый раз очищая очередь. | L−1 и L проходят проверку размера; L+1 отклоняется. Перед подготовкой файлов уточнить единицу MB/MiB. |
| TC-UPL-006 · Очистка | Выбрать корректный файл, очистить очередь и снова выбрать тот же файл. | После очистки очередь пуста. При повторном выборе появляется ровно одна запись с именем, длительностью и статусом валидации. |
| TC-BAL-001 · Нулевой баланс | При балансе 0 секунд выбрать видео длительностью 10 секунд. | Файл можно выбрать; обработка не запускается. |
| TC-BAL-003 · Граница баланса | Загрузить видео длительностью 29, 30, 31 минуты при балансе 30 минут. Между попытками очищать очередь. | При поминутном учёте: 29 и 30 минут — обработка разрешена; 31 — запрещена. |

### Почему проверки устроены так

| Решение | Зачем |
| --- | --- |
| Достаточный баланс при проверке количества и размера | Ошибка одного правила не должна мешать проверить другое. |
| Значения ниже, на границе и выше лимита | Проверить саму границу и допустимость точного равенства. |
| Отдельно проверять выбор файла и запуск обработки | Файл может оставаться доступным для выбора при запрещённой обработке. |
