# Расширенный справочник проверок продукта

Дополнительный материал по Audiodoc Studio, подготовленный с участием владельца продукта и ИИ на основе исходного кода. Он отделён от [примеров работ Елизаветы](../portfolio/test-design-workbook.md): здесь не утверждается, что она самостоятельно составила или выполнила этот расширенный набор.

Пять документов со сценариями содержат **94 предлагаемые проверки**; карта покрытия помогает выбрать нужные. Результатов выполненных проверок здесь нет.

Код показывает реализацию на указанном коммите, но не заменяет согласованные требования и не доказывает поведение работающего сервиса. Неясные правила нужно уточнить у владельца продукта перед выполнением. Развёрнутое приложение в рамках этого обзора не проверялось.

В исходном примере загрузки принято **1700 десятичных МБ (1 700 000 000 байт)**. Справочник использует значение из проверенного кода: **1700 MiB (1 782 579 200 байт)**. Это разные основания для проверки; объединять их можно после согласования единиц.
