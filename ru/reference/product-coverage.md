# Audiodoc Studio — карта покрытия продукта и рисков

**Справочный материал:** покрытие основных сценариев и тестовые данные. [Границы и происхождение материалов](README.md).

## Приоритеты проверок

- **P0:** доступ к аккаунту, сохранность работы, права и учёт времени. Сбои могут заблокировать основной сценарий, привести к потере данных или денег.
- **P1:** остальные важные функции, восстановление после сбоев и совместимость.
- **P2:** оформление и удобство с небольшим влиянием на работу.

Уточняйте приоритеты с учётом изменений в релизе и затронутых пользователей. Если ошибка вёрстки блокирует важное действие, она получает приоритет этого действия.

## Правила продукта

- В очереди допускается не более десяти файлов суммарно, в том числе при последовательном добавлении.
- Указанное в интерфейсе ограничение «1700 MB» реализовано как **1 782 579 200 байт (1700 MiB)**.
- Длительность медиафайла округляется вверх до целых секунд. Если браузер не смог её определить, это может сделать сервер: передача файла тогда предшествует окончательной проверке возможности расшифровки.
- Документ по общей ссылке требует входа в аккаунт. Закрытый доступ, просмотр и редактирование проверяются отдельно.
- При загрузке доступны настройки языка, разделения по спикерам и дословной расшифровки. В изученной версии используется текущая модель без отдельного переключателя.
- Новый редактор с данными на уровне слов доступен отдельно в бета-версии. Его функции и работу со старыми документами нужно проверять отдельно.
- В изученной версии самостоятельный возврат платежей отключён.

## Набор тестовых данных

| Набор | Состав и назначение |
| --- | --- |
| MEDIA-10 | Корректный 10-секундный MP4 для проверки баланса и небольших файлов |
| MEDIA-LONG | Корректный медиафайл длительностью 26:16 для зафиксированного сценария с достаточным балансом |
| COUNT-01…11 | Разные корректные 10-секундные файлы; баланс достаточен, чтобы не влиять на проверку ограничения количества |
| SIZE-LOW/EQUAL/HIGH | Корректные медиафайлы размером 1 782 579 199 / 1 782 579 200 / 1 782 579 201 байт |
| DURATION | Корректные файлы с длительностью около границы целой секунды и файл, для которого подтверждена необходимость определения длительности на сервере |
| TRANSCRIPT | Искусственный текст с двумя спикерами, известным аудио, пунктуацией, повторяющимися словами и заданным порядком сегментов |
| LEGACY | Тестовый старый документ без данных на уровне слов и новый документ с такими данными |
| ACCOUNTS | Владелец A, другой вошедший в аккаунт пользователь B и браузер без входа; для каждого аккаунта задан известный баланс |
| PAYMENT | Платежи в тестовой среде: ожидающий подтверждения, подтверждённый, отклонённый и повторное уведомление |

## Сквозные проверки перед релизом

1. **Основной путь:** вход → выбор медиафайла → проверка условий запуска → обработка → открытие → редактирование → сохранение и перезагрузка → экспорт.
2. **Доступ:** владелец создаёт документ → предоставляет просмотр или редактирование → второй аккаунт открывает документ → права меняются → доступ проверяется повторно.
3. **Учёт времени:** получение тестового баланса → обработка файла с известной длительностью → сверка результата, оставшегося времени и истории.
4. **Восстановление:** прерывание на заданном этапе → проверка сохранённого состояния → повторная попытка → проверка итогового содержимого и учёта времени.

Перед соответствующими проверками убедитесь, что сервисы и тестовая среда платёжного провайдера доступны.
