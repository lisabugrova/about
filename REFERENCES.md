# Testing Methodology References

The QA artifacts in this repository use terminology and test-design approaches from the following sources.

1. **Lee Copeland — *A Practitioner's Guide to Software Test Design*.** Test selection using equivalence classes, boundaries, decision tables, state-based models and combinations.
2. **Святослав Куликов — *Тестирование программного обеспечения. Базовый курс*.** Practical foundations of software testing, requirements analysis, defect reporting and test documentation.
3. **ISTQB — Certified Tester Foundation Level (CTFL), syllabus v4.0.1.** Test analysis and design, coverage, risk-based testing, test execution, defect management and test reporting. [Official syllabus](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf).
